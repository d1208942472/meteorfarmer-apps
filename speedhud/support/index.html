Quick tips

  • Location: allow location access while using the app. Speed HUD uses location only while the app is open. For the best GPS signal, keep the phone where it has a clear view of the sky.
  • HUD mirror mode: shows the speed mirrored so it can be read as a reflection in the windshield. Set it up before you start driving.
  • Trips: trips are stored only on your device. Deleting the app deletes them.

Safety

Always obey local speed limits. Set up the app before you drive, and do not operate your phone while driving. Place the phone so it does not block your view of the road. Speed and HUD readings are for reference only and may be inaccurate when the GPS signal is weak. The speed alert uses the number you set, not the posted limit.
